# Assets visuels LMS ORH

Ce dossier contient les ressources graphiques utilisées dans la génération des présentations PowerPoint.

## Fichiers attendus

### `logo_lms.png`
- Logo LMS ORH (fond transparent recommandé)
- Dimensions recommandées : 200 × 80 px
- Format : PNG avec transparence
- Utilisé : coin bas-droit de la slide de couverture

### `mosaic_lms.jpg`
- Photo mosaïque de visages (équipe, collaborateurs)
- Dimensions recommandées : ~300 × 700 px (portrait)
- Format : JPG ou PNG
- Utilisé : panneau gauche pleine hauteur de la slide de couverture

## Notes

- Si ces fichiers sont absents, le générateur PPT utilisera des fonds de couleur unie (bordeaux) à la place.
- Les fichiers sont ignorés par git (ajoutez-les localement).
- Couleur bordeaux LMS : `#8B1A1A` (RGB 139, 26, 26)
